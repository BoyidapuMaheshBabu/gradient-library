# Gradient Library

An open-source collection of distinctive, reusable gradient backgrounds for modern websites and AI-assisted development.

## What is it?

Browse and preview gradient backgrounds, then copy the CSS code or an AI-ready prompt to use them in your project.

## Initial Focus

- Explore gradients in a simple visual gallery.
- Preview backgrounds before choosing.
- Copy ready-to-use CSS.
- Copy prompts that help AI coding agents implement the selected gradient.

## Vision

Start with background gradients and gradually expand into reusable visual resources and frontend patterns that help AI agents build better products.

# Website Development Phases

## Phase 01 — Website Foundation
Build the first working website with 1–2 gradients. Establish the initial page layout, visual direction, and responsive foundation.

## Phase 02 — Gradient Experience
Add gradient selection and a focused preview.

## Phase 03 — Gradient Editor
Build the gradient editing workspace: customize colors and direction with live preview.

## Phase 04 — Export Experience
Add Copy CSS and Copy AI-ready Prompt actions to the editor workspace, with clipboard handling and success/error feedback.

**Working rule:** Develop one phase at a time. The owner reviews and accepts each phase before moving to the next. Each new phase starts from the latest accepted `main`.
